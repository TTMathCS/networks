# Start here

*Six short lessons for anyone new to networks: young learners, a class, or a grown-up who always wondered. About five minutes each. No computer and no technical words needed; every new word is explained when it first appears.*

| Lesson | The big idea |
| --- | --- |
| [1. What is a network?](01-What-Is-a-Network.md) | Devices joined so they can send each other messages |
| [2. Packets](02-Packets.md) | A big message travels as many small numbered pieces |
| [3. Addresses and names](03-Addresses-and-Names.md) | Every device has an address; names are easier for people |
| [4. Wires and radio waves](04-Wires-and-Radio.md) | Copper, glass fibre and Wi-Fi all carry ones and zeros |
| [5. Staying safe](05-Staying-Safe.md) | Locks, keys and the padlock in your browser |
| [6. Talking to Mars](06-Talking-to-Mars.md) | A network where every hello takes minutes |

**For a class:** each lesson ends with a short game or activity you can do with paper, string or a few friends.

**After these six:** the [Labs](../labs/index.md) let you try the ideas on a real computer, and the first chapters
of [How networks work](../books/networks/index.md) go deeper.
